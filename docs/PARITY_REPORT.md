# Parity report

**Reference:** `com.easyloan.calculator.payment` 1.0.7 (spec bundle `easyloan-spec/Claude_Functionality_First`).
**Replica:** `com.tools.loadapp` 1.0.0.

## Scope decision (read first)

This is a **functional re-implementation with an original visual design**, not a pixel copy:

- No graphics, illustrations or copy were taken from the reference APK. Icons come from the open Material Community Icons set, the launcher icon was generated by `scripts/make-icons.mjs`, and all six locales were written for this project.
- **Visual fidelity against the reference was therefore not a goal.** No overlay or diff images were produced: they would only measure the intended design difference. Layout behaviour (scrolling, keyboard, Back, 360 dp) was verified on the emulator instead. See `EMULATOR_TEST_REPORT.md`.
- Three reference behaviours were **deliberately not reproduced** because they mislead users. See "Intentional deviations".

Status legend: **verified**: implemented, with a unit test and/or an emulator scenario. **implemented**: implemented but not exercised on the device. **provisional**: a bounded behaviour where the reference is unknown. **deferred**: an external integration, by owner instruction. **not built**: a deliberate deviation.

## Intentional deviations (not built)

1. **Paid-cohort-only lending marketing pages** ("Need money fast?", "Need a hand?", "Instant Cash Out"). The app offers no loans or cash. Replaced by a neutral three-page product intro (Next / Skip / dots / Start, persisted completion, IV_ONBOARDING_COMPLETE wired) shown on every first launch.
2. **Fake "Uninstall" launcher shortcut and the uninstall-retention funnel** (offer / reasons pages with interstitial and native ads). It imitates a system action to place ads in front of users who want to leave. The three placements stay as unwired registry keys.
3. **Randomised revenue-source labels** (`rev_adj` 70 / 30, `rev_fir` 80 / 20). This misreports which network earned the revenue. The ledger always keeps the true provider and network.
4. **Raw loan amounts in analytics.** Events carry the type and outcome only.

## Not claimed

- No pixel-level or 100 % parity with the reference.
- No real ad, Firebase or attribution behaviour; no commercial revenue.
- No recovery of the reference's protected native detector.
