# Branding: Repayly

## Name

**Repayly**. Suggested Play Store title: **"Repayly: EMI & Loan Calculator"** (30 characters, the store limit).

- It says what the app is for: repaying a loan. The "-ly" ending makes it a short, ownable word instead of a generic description like "Loan Calc" or "EMI Calculator".
- It works in every app language. The brand is not translated; descriptions are.
- On 2026-11-11 a Google Play search for "Repayly" returned no app with that name. The closest were "REPAYit" (REPAY, a US payments company) and "Paymently".
- A store search is **not** a trademark clearance. Before publishing, search the trademark offices for your markets (USPTO, EUIPO, WIPO Global Brand Database), and check the domain and social handles.

Alternatives if Repayly is taken:

| Name | Notes |
|---|---|
| **Payoffly** | Same idea, more literal ("pay it off") |
| **Loanwise** | Calm and trustworthy, but more likely to clash with existing finance brands |
| **Amortly** | From "amortise"; distinctive, but less obvious to non-specialists |

The name is set in `app.json` (`expo.name`) and as `app_name` / `home_title` in the six string catalogues (`src/i18n/*.ts`). Changing it is a one-line edit plus a rebuild.

## Logo

A **payoff staircase**: three descending bars (a loan balance going down) with a mint check mark rising out of the last one (paid off), on a deep-blue gradient.

| Element | Value |
|---|---|
| Gradient | `#4C8BFF` → `#1B3FBF` (top-left to bottom-right), soft white glow top-left |
| Bars | white at 100 / 92 / 84 % opacity, radius 34 on a 1024 grid |
| Check | mint `#2EE6B0`, 78 px stroke, round caps; in-app accent `#1FC79A` |
| App primary | `#2F6BFF` (unchanged, sits between the two gradient stops) |

It reads at launcher size, has no text inside the icon (Play policy discourages it), and stays inside Android's adaptive-icon safe zone: the furthest visible pixel is 314 px from the centre, against a 341 px safe radius on the 1024 layer (checked by script).
