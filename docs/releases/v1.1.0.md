# Repayly 1.1.0

**Test build.** The APK is signed with React Native's shared debug key. Install it to test; do not publish it to Google Play. A Play release needs your own upload key.

## What's new

**Brand**
- The app is now **Repayly** ("Repayly: EMI & Loan Calculator"), with a new logo: a payoff staircase and check mark.
- New launcher, adaptive and themed (Android 13+) icons and a new splash screen.
- A Play Store icon and feature graphic are in `assets/brand/`.

**Language**
- The app follows the **device language** by default and switches live when the device language changes.
- It supports Android 13+ **per-app language** (Settings → Apps → Repayly → Language).
- A fixed language can still be chosen. The Language page has a new "Use device language" option, and Settings shows "· Auto" while it's in use.

**Usability**
- The result screen starts with a summary card: monthly payment, term and rate, a **principal / interest split bar**, and a **Share** button.
- Field errors stay **under the field** until you edit it, instead of a 3.5-second snackbar.
- Calculation problems (payment too small, total below principal) stay above the Calculate button.
- The keyboard's **Next** moves through the fields and **Done** calculates, on both loan and mortgage forms.
- Language rows give touch feedback, and inputs have accessibility labels.

**Advertising readiness**
- Installs are now classified as **natural or paid traffic** from the Google Play install referrer (Google Ads click ids, paid UTM media, ad-network sources). Before this, every real install was natural.
- The cohort is sent to Firebase as the user property `traffic_cohort`. Ads are still placeholders (no SDK, no unit IDs).
- The reference ad policies are exported as ready-to-paste Remote Config JSON. See `docs/ADS_READINESS.md`.

**Start-up**
- Lazy module loading (Metro inline requires).
- Remote Config fetch, push token and install-referrer reads wait until after the first screen.
- On the test emulator this gave **no measurable change** in cold-start time, which is dominated by native start-up there. See `docs/EMULATOR_TEST_REPORT.md`.

## Tested

- Unit tests 57/57.
- Emulator (Android 17, x86_64): all 48 functional scenarios and all 11 mock-ad scenarios passed on this APK (38 + 9 in full runs, the rest in targeted re-runs after test-script fixes).
- 0 app crashes; 1 ANR seen only under heavy emulator overload.
- Full details in `docs/EMULATOR_TEST_REPORT.md`. arm64 (real phones) is built but was not run.

## Before publishing to Google Play

- Sign with your own upload key (this build uses the shared debug key).
- Restrict the Firebase Android API key to package `com.tools.loadapp` + your release SHA-1 in Google Cloud console.
- Do a trademark check for the name (see `docs/BRANDING.md`).
- Declare Analytics, Crashlytics, the FCM token and the AD_ID permission in the Data safety form (see `docs/FIREBASE.md`).
