# Repayly 1.2.0: first production build

The build for **Google Play**: signed with the Repayly **upload key**, delivered as an App Bundle (`.aab`) for the Play Console and as an APK for direct testing.

## What's new since 1.1.0

**Ready for Google Play**
- Release builds are signed with the owner's upload key (`plugins/withReleaseSigning.js`), not the shared debug key.
- New **App Bundle** build (`.\scripts\android-build.ps1 -Bundle`) for 32-bit ARM, 64-bit ARM and x86_64.
- **No ads and no ad placeholders** anywhere in the app. The developer screen and mock ads exist only in a separate test build, never in this one.
- The advertising-ID and AdServices permissions are removed from the manifest. The app doesn't use the ad ID, and this keeps the Play "Advertising ID" declaration consistent.

**Real legal pages**
- The **Privacy Policy** and **Terms of Use** in the app are now real documents in all six languages, accurate about Firebase, the Play install referrer and the exchange-rate service. Before, these were development placeholders.
- A public English copy for the Play Console is in `docs/legal/`.

**Rate Us**
- 4–5 stars opens Repayly's Google Play listing so you can leave a review.
- 1–3 stars stays in the app as private feedback.

**Store kit**
- Store listing texts, Data safety answers, declarations and a step-by-step upload guide: `docs/PLAY_STORE.md`.
- Play-compliant phone screenshots: `assets/store/screenshots/`. Icon and feature graphic: `assets/brand/`.

Everything from 1.1.0 is included:
- the Repayly brand and logo;
- device-language following;
- result summary with split bar and Share;
- inline errors and keyboard Next / Done;
- traffic-cohort detection;
- Firebase.

## Tested

- Unit tests: 57/57.
- Emulator (Android 17), on this exact APK: all 48 functional scenarios passed (46 in one full run; NOT02 and LEGAL01 after a re-run).
- 0 app crashes, 0 JS errors, 0 ANRs in the device log.
- Signature (upload key), version, CPU types and permissions checked with apksigner / jarsigner / aapt2.
- Full report: `docs/EMULATOR_TEST_REPORT.md`.
- Not tested: a real ARM phone, a real Play install (install referrer from an ad) and a real push message.
